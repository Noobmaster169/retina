# Diagrams

The drawn slides (3, 5, 6, 7, 16, 17, 18) are inline SVG in `../deck.html`, generated by these
scripts. `iso.py` holds the shared shapes (platforms, block arrows, pills, documents).
To change one, edit its script, then from this folder:

```bash
python3 s05.py && python3 put.py '<!-- 05 pipeline -->' s05.svg
cd .. && node render.mjs --png
```

`put.py` replaces the slide's full-page SVG, found by the slide's `<!-- NN name -->` comment.
Slide 7's marker is `<!-- 07 ontology layer -->`.

Brand marks (slide 6) are Simple Icons paths saved under `logos/`, drawn by `logo()` in `iso.py`.
Add one with `curl -o logos/<slug>.svg https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`.
